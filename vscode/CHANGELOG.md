# Historique

## 0.3.0

- K+ Serveur : coloration des fonctions de la bibliothèque serveur (`page`,
  `formulaire`, `enregistrer`, `session`…), correction avec le moteur K+ 0.3.
- Extrait `utiliserserveur`.

## 0.2.0

- K+ Web : mot-clé `utiliser`, coloration des fonctions de la bibliothèque
  web (`titre`, `bouton`, `champ`…), correction avec le moteur K+ 0.2.
- Extraits `utiliserweb` et `bouton`.

## 0.1.0

- Première version : couleurs, correction des erreurs pendant la saisie avec
  le moteur K+ 0.1, exécution dans le terminal, raccourcis d'écriture,
  retrait automatique et commentaires.
